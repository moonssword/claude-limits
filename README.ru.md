# Лимиты Claude

*[English version](README.md)*

Приложение для строки меню macOS: показывает остаток 5-часовой сессии и недельной квоты
Claude, не открывая браузер.

Иконка несёт обе цифры сразу: внешний (верхний) элемент — сессия, внутренний (нижний) —
недельная квота. По клику открывается панель с точными процентами, временем сброса,
прогнозом темпа расхода.

> Неофициальное приложение, не связано с Anthropic. Читает данные вашей собственной
> учётной записи и никуда ничего не отправляет.

## Требования

- macOS 14 или новее
- Подписка Claude и выполненный вход в Claude Code на этой машине (`claude`, затем `/login`)
- Для сборки из исходников: Command Line Tools (`xcode-select --install`)

## Установка

### Из релиза

Скачайте `.dmg` из [Releases](../../releases), перетащите приложение в «Программы», запустите.

Сборки не подписаны Apple Developer ID, поэтому первый запуск блокирует Gatekeeper.
Либо правый клик по приложению → **Открыть** → **Открыть**, либо снимите карантин:

```bash
xattr -dr com.apple.quarantine /Applications/ClaudeUsage.app
```

### Из исходников

```bash
./build.sh                                  # собирает build/ClaudeUsage.app
cp -R build/ClaudeUsage.app /Applications/
open /Applications/ClaudeUsage.app
./make-dmg.sh                               # при желании: build/ClaudeUsage-<версия>.dmg
```

## Откуда берутся данные

Приложение читает OAuth-токен Claude Code из связки ключей (запись `Claude Code-credentials`)
и запрашивает `https://api.anthropic.com/api/oauth/usage` — тот же источник, что у команды
`/usage` внутри Claude Code. Ответ содержит:

| поле             | что это                                         |
|------------------|-------------------------------------------------|
| `five_hour`      | 5-часовая сессия: % использовано и время сброса  |
| `seven_day`      | недельная квота по всем моделям                  |
| `seven_day_opus` | недельная квота Opus, если она есть у плана      |
| `extra_usage`    | дополнительные оплачиваемые кредиты              |

Больше никуда ничего не уходит. История хранится локально в
`~/Library/Application Support/ClaudeUsage/history.json`, результат последнего опроса —
в `status.json` рядом.

### Авторизация

Два режима, переключаются в настройках:

1. **Связка ключей Claude Code** (по умолчанию) — настраивать нечего. macOS один раз на каждую
   сборку спросит разрешение читать запись `Claude Code-credentials`, нажмите
   **«Всегда разрешать»**. После пересборки подпись меняется, и запрос повторяется.
2. **Свой токен** — кнопка **«Авторизоваться через браузер»**: приложение запускает
   `claude setup-token` фоновым процессом, поэтому браузер открывается сразу — без окна
   Терминала и без запроса доступа к автоматизации. Вы входите по уже открытой сессии
   claude.ai, вставляете показанный код обратно в приложение, и долгоживущий токен ложится в
   собственную запись связки ключей. Системных запросов доступа больше не будет. Ручная
   вставка токена тоже осталась.

Собственного OAuth-входа внутри приложения нет намеренно: у Anthropic нет публичной
регистрации сторонних OAuth-клиентов для подписочных аккаунтов, поэтому такой вход пришлось бы
вести под `client_id` самого Claude Code, то есть выдавая приложение за него.
`claude setup-token` даёт тот же браузерный вход штатным путём.

## Что в интерфейсе

**Строка меню.** Одиннадцать вариантов вида: четыре формы индикатора — кольца, две полосы,
батарейка (заряд = остаток сессии) и точки — каждая с необязательной подписью: время до сброса
сессии, проценты использования (`61·41`), остаток сессии или «время · неделя». В настройках они
показаны плитками с живым предпросмотром на светлом и тёмном фоне. Иконка монохромная
(шаблонная, следует теме системы) и окрашивается только у лимита: жёлтый с 75 %, красный с 90 %.
Исчерпано — восклицательный знак, нет связи — пунктирные кольца.

**Панель.** Сессия и неделя крупными цифрами: процент, остаток времени, точка сброса, полоса
заполнения. Ниже — недельная квота Opus и доп. кредиты, если применимо, и оценка темпа
(«темп ~11%/день · прогноз к сбросу ≈ 74 %» либо «квота кончится в пт в 18:20»),
посчитанная по замерам, которые приложение делает во время работы.

**Правый клик** по иконке — «Обновить сейчас» / «Настройки…» / «Выйти».

**Настройки.** Сгруппированы по разделам: оформление, строка меню, обновление, система,
уведомления, авторизация. Язык, тема приложения (как в системе / светлая / тёмная), режим цвета
иконки, частота опроса (1–30 мин, по умолчанию 10), уведомления (одно на окно сессии перед её
сбросом и одно при переходе порога недельной квоты), автозапуск при входе, режим авторизации.

Режим цвета иконки меняет только акцент: сама иконка и подпись всегда следуют теме **системной**
строки меню, а не теме приложения из настроек. В режиме по умолчанию обе части монохромные и
краснеют только при 90 % и выше.

**Языки.** Английский, русский, немецкий, французский, испанский, итальянский, португальский,
арабский (с зеркальной раскладкой), корейский, казахский, киргизский, узбекский. По умолчанию
берётся язык системы. Всё, кроме русского и английского, — машинный перевод; правки удобно
вносить в [`Sources/ClaudeUsage/Strings.swift`](Sources/ClaudeUsage/Strings.swift).

**Частота запросов.** Эндпоинт лимитов ограничен по частоте на уровне аккаунта и отвечает `429`
с бесполезным `Retry-After: 0`, поэтому приложение отступает само: 5, 10, 20, 40 минут при
повторных отказах (не дольше часа), держит минимум минуту между автоопросами и продолжает
показывать последние известные цифры. Ручное обновление игнорирует минимальный интервал,
но не паузу после 429.

## Структура проекта

```
Sources/ClaudeUsage/
  AppMain.swift              точка входа, NSApplication без иконки в Dock
  UsageAPI.swift             чтение токена из связки ключей + запрос лимитов
  Models.swift               модели и ошибки
  UsageStore.swift           опрос, состояние, уведомления, бэкофф
  StatusItemController.swift пункт строки меню, попап, контекстное меню
  StatusIcon.swift           отрисовка индикаторов
  PopoverView.swift          основная панель
  SettingsView.swift         окно настроек
  Preferences.swift          настройки + автозапуск (SMAppService)
  AuthFlow.swift             авторизация через браузер (claude setup-token)
  TokenStore.swift           собственная запись связки ключей для своего токена
  History.swift              локальные замеры и оценка темпа
  Format.swift               форматирование времени, процентов, цвета статуса
  PreviewRenderer.swift      `ClaudeUsage --render <каталог>` — снимки интерфейса в PNG
  L10n.swift, Strings.swift  локализация (96 ключей × 12 языков)
Tools/make-icon.swift        генератор иконки приложения
build.sh                     сборка .app
make-dmg.sh                  сборка .dmg
```

## Выпуск релиза

Поставьте тег и запушьте его — [`.github/workflows/release.yml`](.github/workflows/release.yml)
соберёт DMG на macOS-раннере и приложит к релизу GitHub:

```bash
git tag v1.0.0 && git push origin v1.0.0
```

Выкладывать неподписанный бинарник можно и это обычная практика — пользователю нужно снять
карантин, как описано выше. Чтобы Gatekeeper пропускал молча, нужна подписка Apple Developer
Program (99 $/год): подпись сертификатом Developer ID и нотаризация через
`xcrun notarytool submit … --wait` и `xcrun stapler staple`.
